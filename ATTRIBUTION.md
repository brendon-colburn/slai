## STS2MCP

SLAI is a pure HTTP client of [STS2MCP](https://github.com/Gennadiyev/STS2MCP) by **Yikun Ji (Kunologist)**, licensed under MIT. We do not redistribute any STS2MCP code in this repository. SLAI users must install STS2MCP separately (see its README).

The decision to expose `master_deck` on every screen — needed for coaching to work between combats — is contributed as an upstream PR to STS2MCP, not vendored here.
